ABOUT THE TECHNOHALO ▼

TechnoHalo is a micro:bit-based circular RGB device with 24 programmable RGB LEDs.

The micro:bit adds programmable buttons, a 5x5 LED matrix, a touch-sensitive logo, microphone, speaker, and wireless radio communication. These allow one Halo to send messages to another and respond with lights, symbols, numbers, or sounds.

For this activity, several Table Halos act as restaurant tables while one Master Halo acts as the counter display.

INPUTSButton A = CALL
Button B = RESOLVED
PROGRAMSend table ID and call status using radio
OUTPUTSRGB ring + micro:bit matrix + table number display

HOW THE REAL SYSTEM SHOULD WORK

Press Button A on a Table Halo -> it sends its table number to the Master Halo -> both indicate an active call in red -> the Master displays the requesting table number.

Press Button B after assistance -> the Table Halo sends a resolved message -> the table turns blue and the Master returns to green with a heart.
